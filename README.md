Lab5Web — Praktikum JavaScript Dasar

Repository ini dibuat untuk memenuhi tugas Praktikum 5 mata kuliah Pemrograman Web, dengan materi JavaScript Dasar dan Manipulasi HTML.

Praktikum ini bertujuan untuk memahami penggunaan JavaScript dalam mengolah data dan memanipulasi elemen HTML.

Tujuan Praktikum

Memahami penggunaan JavaScript dasar.

Memahami variabel, fungsi, percabangan, dan event.

Mempraktikkan manipulasi elemen HTML menggunakan JavaScript.

Membuat kalkulator nilai mahasiswa sederhana.
