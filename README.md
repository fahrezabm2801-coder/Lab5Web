## C. Mini Project — Kalkulator Nilai Mahasiswa

Mini project ini mengembangkan penggunaan function, operasi aritmetika, percabangan, dan manipulasi HTML untuk menghitung nilai akhir mahasiswa.

Bobot penilaian yang digunakan:

- Nilai tugas: 30%
- Nilai UTS: 30%
- Nilai UAS: 40%

Program menentukan nilai akhir, predikat, dan status kelulusan mahasiswa berdasarkan hasil perhitungan.

### Skenario 1

Screenshot berikut menunjukkan pengujian pertama kalkulator nilai mahasiswa menggunakan nilai tugas, UTS, dan UAS yang dimasukkan ke dalam program.


### Skenario 2

Pengujian kedua dilakukan menggunakan kombinasi nilai yang berbeda untuk memastikan program dapat menghitung nilai akhir dan menentukan predikat serta status kelulusan sesuai hasil perhitungan.


### Skenario 3

Pengujian ketiga dilakukan untuk memeriksa hasil kalkulasi pada kombinasi nilai lainnya. Ketiga skenario digunakan untuk memastikan fungsi perhitungan dan penentuan hasil bekerja sesuai ketentuan program.
